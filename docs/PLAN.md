## 2. デザイン方向性

### コンセプト
**「ミルクの島のトラベルガイド誌」**
島＝ゲームの世界、名物＝乳製品、巻頭特集＝練乳術、住人インタビュー＝キャラ紹介、ガイドの小コラム＝こだわりUI。

### 参考ビジュアル（ユーザー提供：観光パンフのテンプレ画像「TOURISM MANUAL」）
「だいぶイメージに近い。これをもう少し柔らかく」。読み取れる特徴と、柔らかくする方法：

| 参考画像の特徴 | 柔らかくするなら（案） |
|---|---|
| 白ベース・大きな余白・整ったグリッド | 白 → ミルクホワイト／紙の質感。余白とグリッドはそのまま |
| 写真をひし形・三角形で切り抜き | 角を丸める or **しずく型・卵型**（ゲームの爪スロットの形）で切り抜き。縁は水彩のにじみ |
| 青一色のアクセント、半透明の図形を重ねる | 淡いラグーン色＋琥珀を少し。重なりは水彩の透け感で |
| 太いサンセリフ見出し＋細い英字サブコピー | 丸みのある見出し書体＋細い英字（下記タイポ参照） |
| 写真（ヤシ・ビーチ） | 水彩のキービジュアル・スクショ・乳製品アート |
| アイコン付きの箇条書き・小さな情報ブロック | そのまま流用（作品情報・システム説明に合う） |

※テンプレ画像は透かし入りの有料素材。**参考のみで、素材自体は使わない**

### トーン
- 基本は**参考画像のような、清潔で整った観光パンフ**。そこに水彩と丸みで柔らかさを足す
- 水彩：空・海・草原は淡い水彩のにじみ。ゲーム内の「水彩タッチの乳製品アート」と地続きにする
- 西洋：欧文の英字コピー、ガイドブック風の小見出し
- 可愛い：丸み・パステル・ミルク瓶などの小物。スタンプやステッカーは使うとしても少量（参考画像の清潔感を優先）
- 避ける：ギラギラのUI枠、発光、ガチャ風の立ち絵ドーン（キャラはパンフの紹介ページのように出す）

## 4. 技術方針（既存を使う）

| 項目 | 方針 | 理由 |
|---|---|---|
| 構成 | 既存サイトと同じ**素のHTML/CSS/JS** | 既存の仕組み（オープニング、フェードイン、SYSTEMの切替UI、nav.js）を流用でき、編集の流れも変わらない |
| 画像最適化 | 公開前にWebP/AVIFへ一括変換（既存のCLIツール） | 水彩・スクショは重い |
| フォント | Google Fonts（既存で読み込み中のものを中心に） | 既存と同じ |
| 水彩の質感 | 本物の水彩素材＋SVGフィルターは装飾の補助のみ | CSSだけで本物の水彩は作れない |
| 動き | CSS＋IntersectionObserver、`prefers-reduced-motion` 対応 | 既存と同じ方針 |
| 公開先 | 既存の milkemist.com の運用に合わせる | 公開設定の変更は事前に確認を取る |

## 6. 懸念・反対意見

1. **資料どうしの食い違い**（詳細は NOTES.md）。特に練乳術のルールと対象年齢は、サイトの主役と見せ方を左右するので確定が先
2. **対象年齢と「可愛い」テイスト**：R-18なら、入口での明示／年齢確認を推奨。全年齢〜ライトなら不要だが、お色気要素の見せ方の線引きは決めておきたい
3. **ポケモン・Netflixは“雰囲気の参考”まで**：名前・ロゴ・似たデザインは使わない
4. **島の水彩キービジュアルが無いと成立しない**：表紙の絵が印象の大半を決める。モックは仮素材で作れるが、本番用の手配が必要
5. **作業量**：体験デモ（A案）は強いが手間もかかる。モックでは最小構成で触り心地を試すのを提案
