## 1. ゴール

- Milkemist のゲームの公式ホームページを作る
- 第一印象は「ゲームの宣伝」ではなく「**南の島の上質な旅行パンフレット**」
- それでいて、ゲームの基本情報（ジャンル・対応機種・発売日・購入先）は迷わず見つかる

## 2. デザイン方向性

### コンセプト
**「架空の島の観光パンフレット」**
ゲームの世界＝旅先。サイトを読む＝旅の下調べ。購入＝航空券を手に入れる。

### キーワード
南国 / 水彩 / 紙の質感 / 余白 / 上品 / 静けさ / 旅情

### やること
- 水彩のにじみ・紙のテクスチャ・余白多めの雑誌的レイアウト
- 明朝＋セリフ体の落ち着いたタイポグラフィ、和文見出しは縦書きも検討
- 旅モチーフ：島の地図、ポストカード、切手・消印、エアメール柄、搭乗券
- 植物モチーフ：モンステラ、ハイビスカス、ヤシの葉（水彩、画面の端にさりげなく）

### やらないこと（＝アニメゲームっぽさの回避）
- トップに大きなキャラ立ち絵
- ネオン・強いグラデーション・発光エフェクト
- ゲームUI風の枠、ゴシック太字の煽りコピー
- 過剰なパララックスや派手なアニメーション
- 丸っこい「かわいい」フォント

### カラー（案）
| 役割 | 色 | 用途 |
|---|---|---|
| 紙（背景） | `#F6F0E4` | ベース。真っ白にしない |
| インク（文字） | `#2B3A3A` | 本文。真っ黒にしない |
| ラグーン | `#7FD1C7` / `#3FB6B2` | メインの水彩ウォッシュ |
| 深い海 | `#1F5F7A` | 見出し・リンク |

| 陽ざし | `#F2C76E` | ハイライト |

### タイポグラフィ（Google Fonts、すべて無料）
- 欧文見出し：Cormorant Garamond（イタリック多用）
- 和文見出し：Shippori Mincho B1 または Zen Old Mincho
- 本文：Zen Kaku Gothic New（細め）
- 手書きアクセント：使うなら最小限（ポストカードの添え書き程度）

## 4. 技術方針（既存のものを使う）

| 項目 | 推奨 | 理由 / 代替 |
|---|---|---|
| フレームワーク | **Astro** | 画像の自動最適化（水彩画像は重いのでWebP/AVIF化が重要）、多言語ルーティング標準搭載。代替：素のHTML/CSS（ビルド不要で編集が楽、ただし画像最適化は手作業） |
| ホスティング | **GitHub Pages**（無料） | このリポジトリから公式手順で自動デプロイ可能。代替：Cloudflare Pages / Netlify（無料枠） |
| フォント | Google Fonts | 上記 |
| 水彩の質感 | 本物の水彩素材 ＋ SVGフィルター（feTurbulence / feDisplacementMap） | CSSだけで「本物の水彩」は作れない。フィルターは装飾・にじみ表現の補助に限定 |
| 紙テクスチャ | SVGノイズ or 無料テクスチャ画像 | ライセンス確認必須 |
| アニメーション | CSS ＋ IntersectionObserver（ふわっと出る程度） | ライブラリ不要。動きは控えめに |
| アクセシビリティ | `prefers-reduced-motion` 対応、代替テキスト、コントラスト確保 | 淡い水彩色の上の文字は特に注意 |

## 5. 素材の調達（ここがデザインの質を決める）

| 素材 | 方針 |
|---|---|
| キービジュアル（表紙の水彩画） | **最重要**。本物の水彩イラストを推奨（自作 / 依頼）。無い間は仮素材で組む |
| 島の地図 | ゲーム内マップを水彩風に描き起こすのが理想 |
| 植物・装飾 | 無料素材（パブリックドメイン/CC0の植物画など）を探して活用 |
| スクショ | ゲームから。ポストカード枠に入れて世界観に馴染ませる |
| ロゴ | 既存があれば使用 |

## 6. 懸念・反対意見

1. **「アニメっぽくない」とゲーム実物のギャップ**
   ゲーム自体がアニメ調の場合、サイトだけ上品にすると「思ってたのと違う」になりかねない。
   → スクショは必ず見せる。ただしポストカード風に額装して世界観を崩さない形を提案。
2. **水彩の質は素材次第**
   コードで水彩“風”は作れるが、安っぽくなりやすい。表紙だけは本物の絵を強く推奨。
3. **パンフ演出が基本情報を埋もれさせる危険**
   「どんなゲーム？いつ出る？どこで買える？」は表紙直下か固定ナビで常に1クリック以内に。
4. **画像が重くなる**
   水彩・紙テクスチャは容量が大きい。画像最適化前提で設計（Astro推奨の理由）。
